# Wadley Eugene — Portfolio Website

A responsive, dark premium personal portfolio starter for Wadley Eugene.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive dark/gold design
- `script.js` — language switcher, mobile navigation, copy-email button
- `assets/` — add your photos here

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a smoother local development workflow, open the folder in VS Code and use the Live Server extension.

No build tools are required.

## Add your portrait
Place your portrait at `assets/wadley-portrait.jpg`. The page will automatically show it in place of the initials placeholder. Use a reasonably high-quality portrait image.

## Add project screenshots
The TreatSpin section currently uses a stylized code illustration rather than a real screenshot. Replace that artwork in `index.html` with your own screenshot once ready. Update the project description with only details that accurately describe the current app.
